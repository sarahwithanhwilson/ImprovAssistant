# Improv Assistant Logo

![Improv Assistant Logo](assets/logo.png)

## Design Overview

The Improv Assistant logo features a cheerful comedy mask design that represents the spirit of improvisation and performance.

### Design Elements

- **Comedy Mask**: A smiling face with happy eyes representing the joy and creativity of improv comedy
- **Color Scheme**: Material Design Indigo (primary color: #3F51B5) matching the app's theme
- **Microphone Accent**: A gold microphone icon at the bottom symbolizing performance and stage work
- **Style**: Clean, modern, and playful - suitable for both professional and casual contexts

### Technical Details

The logo has been generated in all required sizes for both platforms:

#### Android Icons
- **Launcher Icons**: Available in all density buckets (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi)
- **Round Icons**: Circular variants for devices that support round icons
- **Foreground Icons**: Adaptive icon foregrounds for Android 8.0+
- **Web Icon**: 512x512px version for web use

#### iOS Icons
- All required sizes from 20x20 to 1024x1024
- Multiple scale factors (@1x, @2x, @3x)
- Compliance with Apple App Store requirements

### Color Palette

- **Primary Indigo**: `#3F51B5` (Material Design Indigo 500)
- **Dark Indigo**: `#303F9F` (Material Design Indigo 600)
- **Light Indigo**: `#5C6BC0` (Material Design Indigo 400)
- **Accent Gold**: `#FFD700` (For microphone icon)
- **White**: `#FFFFFF` (For the mask face)

### Files

All icon files are located in their respective platform directories:
- Android: `android/app/src/main/res/mipmap-*/`
- iOS: `ios/Runner/Assets.xcassets/AppIcon.appiconset/`
- Documentation: `docs/assets/logo.png`

## Regenerating Icons

If you need to regenerate the icons with modifications, use the Python script that was used to create these icons. The script uses Pillow (PIL) to generate all required sizes automatically.
